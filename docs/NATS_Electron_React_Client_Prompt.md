# NATS 可视化调试客户端开发 Prompt

## 技术栈：Electron + electron-vite + React + TypeScript

你是一名资深桌面端架构工程师。

请使用 **Electron + electron-vite + React + TypeScript** 开发一个用于
NATS 调试和测试的可视化桌面客户端。

要求：工程结构清晰、可扩展、可长期维护、适合后续插件化。

------------------------------------------------------------------------

# 一、技术栈要求

-   Electron
-   electron-vite
-   React 18
-   TypeScript
-   Node.js
-   官方 nats.js 客户端
-   Zustand 状态管理
-   Ant Design 组件库
-   IPC 进行主进程与渲染进程通信
-   ESLint + Prettier

------------------------------------------------------------------------

# 二、功能需求

## 1. 连接管理

-   输入 NATS Server 地址
-   端口
-   用户名 / 密码
-   Token
-   TLS 开关
-   支持保存多个连接（本地 JSON 持久化）
-   自动重连机制
-   显示连接状态（已连接 / 断开 / 重连中）

------------------------------------------------------------------------

## 2. Publish 功能

-   输入 Subject
-   输入 JSON 或文本消息体
-   发送一次
-   定时发送
-   压测模式（支持指定 QPS）
-   显示发送统计（成功数 / 失败数 / 速率）

------------------------------------------------------------------------

## 3. Subscribe 功能

-   输入 Subject（支持通配符）
-   支持多个订阅
-   显示消息列表：
    -   时间
    -   Subject
    -   Payload
-   JSON 自动格式化
-   搜索过滤
-   暂停滚动
-   清空消息
-   默认最大缓存 1000 条（可配置）

------------------------------------------------------------------------

## 4. Request / Reply

-   输入 Subject
-   输入请求内容
-   显示响应时间
-   显示响应结果

------------------------------------------------------------------------

## 5. JetStream 支持

-   查看 Stream 列表
-   查看 Consumer 列表
-   手动拉取消息
-   ACK / NACK

------------------------------------------------------------------------

# 三、架构设计

目录结构：

src/ main/ nats/ NatsService.ts ipc/ index.ts renderer/ components/
pages/ store/ hooks/

要求：

-   所有 NATS 逻辑在主进程
-   渲染进程通过 IPC 调用
-   主进程封装 NatsService 类：
    -   connect()
    -   disconnect()
    -   publish()
    -   subscribe()
    -   request()
-   使用 EventEmitter 向渲染进程推送消息

------------------------------------------------------------------------

# 四、性能要求

-   支持高频订阅（\>= 10k msg/s）
-   使用虚拟列表渲染
-   UI 不阻塞
-   消息列表限制最大条数防止内存泄漏

------------------------------------------------------------------------
